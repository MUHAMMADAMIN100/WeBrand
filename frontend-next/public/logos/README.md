# Логотипы — инструкция по загрузке

## Куда класть
Все логотипы — в эту папку: `public/logos/`

## Формат
- **SVG** — желательно (масштабируется идеально)
- Или **PNG** с прозрачным фоном, минимум 400×400 px
- Размер файла — до 200 КБ
