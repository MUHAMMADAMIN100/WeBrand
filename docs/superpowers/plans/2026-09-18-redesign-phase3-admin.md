# Редизайн WeBrand — Этап 3: админ-панель

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Перевести админку (`admin-panel/`, Vite + React 18 + Tailwind 3.4) на дизайн-систему сайта — те же токены, два шрифта, лайм как единственный акцент — и добавить главную-дашборд. Функционал один в один; бэкенд не меняется.

**Architecture:** Палитра меняется в одной точке: шкала `neutral` в `tailwind.config.js` переопределяется на `ink` сайта, поэтому все 6 300 строк разметки сразу получают новый тон, а руками правятся только кит компонентов, каркас (сайдбар, топбар, вход) и то, что должно выглядеть иначе. Дашборд — новая страница `/` на существующих эндпоинтах, данные считаются на клиенте.

**Tech Stack:** Vite 5 · React 18 · Tailwind 3.4 · dnd-kit · lucide. Добавляются `clsx` + `tailwind-merge@2` (для `cn()`), шрифт Unbounded (Google Fonts, кириллица).

**Spec:** `docs/superpowers/specs/2026-09-17-webrand-redesign-design.md` §6, §7, §9.

## Global Constraints

- `main` не трогать. Коммиты заканчиваются `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Не менять: API-клиент, токены/refresh, контракты (`slug` ↔ `id`, словари `options.ts`), drag-and-drop как единственный способ сортировки, multipart для логотипов/обложек, тексты ошибок сервера.
- Обе темы (`darkMode: 'class'`, ключ `wb_admin_theme`) сохраняются; движение сдержанное (150–250 мс); плотность компактная.
- Гейт: `npm run build` (tsc -b + vite) без ошибок; Playwright-прогон `test_admin.py`: вход, каждый раздел без ошибок консоли, CRUD вакансии, сортировка клавиатурой, переключение темы, цифры дашборда = цифрам API; 375/768/1440.
